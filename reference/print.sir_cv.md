# Print rolling-origin cross-validation results

Print rolling-origin cross-validation results

## Usage

``` r
# S3 method for class 'sir_cv'
print(x, digits = 3, ...)
```

## Arguments

- x:

  a `sir_cv` object returned by
  [`cv_sir`](https://netify-dev.github.io/sir/reference/cv_sir.md).

- digits:

  integer; number of decimal places to display.

- ...:

  unused.

## Value

Invisibly returns `x`.
