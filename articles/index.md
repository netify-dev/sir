# Articles

### Getting Started

- [Getting Started with Social Influence
  Regression](https://netify-dev.github.io/sir/articles/sir_overview.md):

  Fit a SIR model, read influence matrices, and use model-implied
  scenarios on simulated and ICEWS data.

- [Inference and model
  comparison](https://netify-dev.github.io/sir/articles/sir_inference.md):

  Choose classical, robust, cluster, bootstrap, jackknife, and
  predictive checks for SIR fits.

- [Distribution families, network types, and data
  preparation](https://netify-dev.github.io/sir/articles/sir_extensions.md):

  Use Normal and Binomial outcomes, symmetric and bipartite networks,
  dynamic influence covariates, and array builders.

### Methods Reference

- [SIR
  Methodology](https://netify-dev.github.io/sir/articles/methodology.md):

  Mathematical reference for the SIR likelihood, identification,
